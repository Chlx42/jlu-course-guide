## 学习建议

- **理论部分**:
  - 关系模型: 关系代数、关系演算
  - SQL 语言: SELECT/INSERT/UPDATE/DELETE,多表查询,子查询,聚合函数
  - 数据库设计: E-R 图、范式理论(1NF/2NF/3NF/BCNF)、模式分解
  - 事务管理: ACID 特性、并发控制(锁机制)、故障恢复

- **实践部分**:
  - 熟练掌握 SQL 语法,多做查询练习
  - 课程设计尽早开始,选题要合理(不要太复杂也不要太简单)
  - 推荐使用 MySQL 或 PostgreSQL,有大量学习资源
  - 学习使用数据库管理工具(Navicat、DBeaver 等)

- **考试重点**:
  - SQL 查询(必考,分值高)
  - 关系代数表达式
  - E-R 图设计
  - 范式判断和模式分解
  - 事务和并发控制

## 常见问题

**Q: 这门课难吗?**  
A: 相比操作系统和编译原理,难度适中。SQL 语法需要多练习,理论部分理解核心概念即可。

**Q: 需要提前学 SQL 吗?**  
A: 不需要,课程会从头讲。但课后要多练习才能熟练。

**Q: 课程设计做什么?**  
A: 一般是设计并实现一个小型数据库应用系统(如图书管理、学生选课、电商后台等)。需要画 E-R 图、建表、实现增删改查功能,可以配简单的前端界面。

**Q: 用什么数据库?**  
A: 课程可能统一要求,如果自选推荐 MySQL(资料多、轻量)或 PostgreSQL(功能强、标准)。
