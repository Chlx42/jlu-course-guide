## 📖 课程内容

### 编译器全流程

```
源代码 (SNL)
    ↓
┌─────────────────┐
│  词法分析        │  Token 流
│ (Lexer)         │  int, id, =, num, ;
└─────────────────┘
    ↓
┌─────────────────┐
│  语法分析        │  语法树
│ (Parser)        │  Program → DecList → StmtList
└─────────────────┘
    ↓
┌─────────────────┐
│  语义分析        │  符号表 + 类型检查
│ (Semantic)      │  变量声明了吗？类型匹配吗？
└─────────────────┘
    ↓
┌─────────────────┐
│ 中间代码生成     │  三地址码
│ (IR Gen)        │  t1 = a + b
└─────────────────┘
    ↓
┌─────────────────┐
│ 代码优化         │  常量折叠、死代码消除
│ (Optimizer)     │  (可选)
└─────────────────┘
    ↓
┌─────────────────┐
│ 目标代码生成     │  TM 指令
│ (CodeGen)       │  LD, ST, ADD, JMP...
└─────────────────┘
    ↓
可执行文件 (TM 执行)
```

### 理论重难点

| 章节 | 难度 | 考试占比 | 核心概念 |
|------|------|---------|---------|
| 词法分析 | ⭐⭐ | 15% | 正则表达式 → NFA → DFA |
| 语法分析 | ⭐⭐⭐⭐⭐ | 40% | **最难**：First/Follow集、LL(1)、LR分析表 |
| 语义分析 | ⭐⭐⭐ | 20% | 属性文法、符号表、类型检查 |
| 中间代码 | ⭐⭐ | 10% | 三地址码、语法制导翻译 |
| 代码优化 | ⭐⭐⭐ | 10% | 数据流分析、优化方法 |
| 目标代码 | ⭐⭐ | 5% | 寄存器分配、指令选择 |

## 🔨 SNL 编译器大作业

### 项目规模

- **代码量**：2000-5000 行（视语言和实现方式）
- **耗时**：40-80 小时
- **建议工期**：4-6 周
- **组队方式**：1-3人（推荐2人）

### 开发路线（6周计划）

#### Week 1-2：词法+语法分析

**目标**：能够读入 SNL 代码，输出语法树

**任务清单**：
- □ 定义 Token 类型（关键字、标识符、运算符等）
- □ 实现词法分析器（手写或用 Lex/Flex）
- □ 根据 SNL 文法构建语法分析器（递归下降推荐）
- □ 测试：能正确解析简单的 SNL 程序
- □ 输出语法树（调试用）

**避坑指南**：
- 不要纠结工具选择，手写递归下降最快上手
- 语法树节点设计要扩展性好（后面要加类型、作用域信息）
- 每完成一个模块立刻写测试用例

#### Week 3-4：语义分析

**目标**：构建符号表，完成类型检查

**任务清单**：
- □ 设计符号表结构（变量名、类型、作用域、地址）
- □ 遍历语法树，填充符号表
- □ 实现作用域管理（函数/过程的嵌套作用域）
- □ 类型检查（表达式类型、赋值兼容性）
- □ 错误处理（未声明变量、类型不匹配等）

#### Week 5：中间代码生成

**目标**：从语法树生成三地址码

**任务清单**：
- □ 设计三地址码指令格式
- □ 实现表达式翻译（后缀遍历语法树）
- □ 实现语句翻译（if/while/for 的跳转）
- □ 函数调用处理（参数传递、返回值）
- □ 生成中间代码文件

#### Week 6：目标代码生成 + 测试

**目标**：生成 TM 虚拟机指令，通过测试

**任务清单**：
- □ 学习 TM 指令集（LD/ST/ADD/SUB/JMP等）
- □ 从三地址码翻译到 TM 指令
- □ 寄存器分配（简单策略即可）
- □ 生成 .tm 文件
- □ 在 TM 虚拟机上运行测试
- □ 准备答辩 PPT 和文档

## 📝 考试攻略

### 题型分布（往年参考）

| 题型 | 分值 | 考察内容 |
|------|------|---------|
| 选择题 | 15分 | 概念、编译阶段、文法类型 |
| 填空题 | 20分 | First/Follow集、产生式 |
| 计算题 | 35分 | LL(1)/LR分析表构造 |
| 综合题 | 30分 | 属性文法、代码翻译 |

### 必考知识点（背熟）

#### 1. 文法改写（每年必考）

**消除左递归**：
```
原文法:  A → Aα | β
改写后:  A → βA'
        A' → αA' | ε
```

**提取左公因子**：
```
原文法:  A → αβ1 | αβ2
改写后:  A → αA'
        A' → β1 | β2
```

#### 2. First 和 Follow 集（送分题）

**First(α)**：从 α 能推导出的**首终结符**集合

**Follow(A)**：A 后面可能跟的**终结符**集合

#### 3. LL(1) 分析表构造（高频大题）

**判断是否为 LL(1) 文法**：
- 每个单元格最多一个产生式
- 对 A → α | β，First(α) ∩ First(β) = ∅
- 若 α → ε，则 First(α) ∩ Follow(A) = ∅

### 答题策略

1. **时间分配**：选择填空 40min，计算题 80min
2. **先易后难**：First/Follow 集先算，LL(1) 表最后填
3. **列步骤**：分析表构造要写过程，有步骤分
4. **检查**：LL(1) 表填完检查是否有冲突
