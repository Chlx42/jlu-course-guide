## 课程评价

## 学习建议

- **理论部分**: 理解进程/线程、同步互斥、死锁、内存管理、文件系统等核心概念
- **实验部分**: 建议提前预习实验内容,实验量大,尽早开始
- **考试重点**: 往年题很有参考价值,重点关注进程调度、页面置换算法、死锁检测等经典问题
- **编程语言**: 实验一般用 C 语言,需要较好的 C 语言基础

## 常见问题

**Q: 这门课难吗?**  
A: 理论概念较多且抽象,实验代码量大,需要投入较多时间。但只要跟上进度,理解核心原理,通过不难。

**Q: 需要 Linux 基础吗?**  
A: 实验环境一般在 Linux 下,建议提前熟悉基本命令和 GCC 编译工具链。
