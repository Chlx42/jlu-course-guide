## 📖 课程内容

### 知识地图

```
线性结构 (40%)
├─ 数组、链表
├─ 栈与队列
└─ 串

树形结构 (30%)
├─ 二叉树遍历
├─ 二叉搜索树
├─ 平衡树(AVL)
└─ 哈夫曼树

图论基础 (20%)
├─ 图的存储(邻接矩阵/表)
├─ 遍历(DFS/BFS)
└─ 最短路径、最小生成树

查找与排序 (10%)
├─ 哈希表
└─ 常见排序算法
```

### 重难点拆解

| 章节 | 难度 | 考试占比 | 学习建议 |
|------|------|---------|---------|
| 线性表 | ⭐⭐ | 25% | 重点掌握链表操作（插入、删除、反转） |
| 栈与队列 | ⭐⭐ | 15% | 理解后缀表达式、括号匹配经典题 |
| 树 | ⭐⭐⭐⭐ | 35% | **最难最重要**，三种遍历要滚瓜烂熟 |
| 图 | ⭐⭐⭐ | 15% | DFS/BFS 模板背熟，最短路理解思路 |
| 查找排序 | ⭐⭐ | 10% | 时间复杂度分析是考点 |

## 💡 学习路线

### 阶段一：打基础（Week 1-6）

**目标**：跟上课程进度，理解基本概念

```mermaid
graph LR
    A[听课/看PPT] --> B[手写代码实现]
    B --> C[完成PTA作业]
    C --> D[总结笔记]
```

**Tips**：
- 每学一个数据结构，必须**手写一遍完整实现**（不要只看代码）
- PPT 上的例题要自己推导一遍
- PTA 不要直接看答案，卡住了先查资料再看题解

### 阶段二：刷题强化（Week 7-12）

**目标**：提升代码能力，应对上机考试

| 题型 | 推荐题量 | 资源 |
|------|---------|------|
| 链表 | 10-15题 | LeetCode 链表标签 |
| 树 | 15-20题 | 前中后序遍历、BST操作 |
| 图 | 5-10题 | DFS/BFS模板题 |

**刷题策略**：
1. 先做简单题找感觉（Easy → Medium）
2. 同类型题目集中刷（比如连续刷5道链表题）
3. 不会的题看题解后**第二天重做一遍**

### 阶段三：考前冲刺（考前2周）

**第一周**：
- 刷往年试卷 2-3 套（掐时间模拟）
- 整理错题本，重点复习薄弱环节
- 背诵常考算法的时间/空间复杂度

**第二周**：
- 回顾 PPT 上的例题和证明
- 手写高频代码（链表反转、树的遍历、DFS/BFS）
- 考前一天看错题本，早点睡

## ⚠️ 常见陷阱

{{< callout type="warning" emoji="⚡" >}}
**血泪教训（学长学姐总结）**
{{< /callout >}}

1. **"光看不练"魔咒**  
   ❌ 只看PPT/视频，不写代码  
   ✅ 每个数据结构至少手写实现一遍

2. **指针操作翻车**  
   ❌ 链表操作不画图，脑补指针变化  
   ✅ 纸上画图，理清楚 `prev/curr/next` 关系

3. **递归理解不透**  
   ❌ 死记递归代码，不理解调用过程  
   ✅ 树的递归问题画递归树，跟踪几层调用

4. **PTA抄答案**  
   ❌ 直接复制粘贴往届代码  
   ✅ 理解思路后自己重新写一遍

5. **考前突击刷题**  
   ❌ 考前一周才开始刷 LeetCode  
   ✅ 平时每周刷 5-10 道，积少成多

## 📝 考试攻略

### 题型分布（参考）

| 题型 | 分值 | 考察内容 |
|------|------|---------|
| 选择题 | 20分 | 概念、复杂度分析 |
| 填空题 | 15分 | 代码补全、输出结果 |
| 算法设计 | 25分 | 手写代码（链表/树操作） |
| 综合应用 | 40分 | 图/树的遍历、查找算法 |

### 高频考点（必背）

✅ **送分题**：
- 三种树的遍历（前/中/后序）
- 栈和队列的基本操作
- 哈希表的冲突解决方法

✅ **拉分题**：
- 二叉搜索树的插入/删除（画图推导）
- 图的 DFS/BFS 遍历顺序
- 最短路径算法（Dijkstra）

✅ **时间复杂度分析**（每年必考）：
- 快排平均 O(nlogn)，最坏 O(n²)
- 二分查找 O(logn)
- 哈希表查找平均 O(1)

### 答题策略

1. **时间分配**：选择填空 30min，编程题 90min
2. **先易后难**：会做的先拿分，难题最后攻
3. **画图思考**：链表、树的题目一定在草稿纸上画图
4. **检查边界**：空表、单节点、左右子树为空等特殊情况

## 🎓 课程设计

### 题目类型

一般是三选一：
1. **校园导航系统**（图的应用，最短路径）
2. **表达式求值**（栈的应用，后缀表达式）
3. **哈夫曼编码**（树的应用，文件压缩）

### 高分要点

✅ **基本要求**（60-70分）：
- 功能完整，能正确运行
- 代码有注释，逻辑清晰

✅ **加分项**（70-85分）：
- 界面友好（简单的菜单即可）
- 异常处理（输入检查、边界情况）
- 代码规范（命名、缩进、模块化）

✅ **满分冲刺**（85-95分）：
- 算法优化（比如用邻接表代替邻接矩阵节省空间）
- 测试完备（提供多组测试用例）
- 文档详细（设计思路、数据结构选择理由）

**时间建议**：提前 2 周开始，不要拖到最后一周
