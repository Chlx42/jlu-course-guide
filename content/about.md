# 关于吉大课程攻略

## 我们在做什么

吉林大学有不少同学整理并开源了课程资料，但它们分散在多个 GitHub 仓库中:

- 找资料需要翻多个仓库
- 没有统一的搜索入口
- 同一门课的资料可能散落在不同地方
- 新生不知道从哪里开始

**吉大课程攻略** 做的事情很简单:**把这些资料聚合起来，按课程和老师归类，让大家能快速找到需要的内容**。
