## 🎨 设计原则

### 用户根本需求
1. **快速评估**：这门课难不难？→ 速览卡片 + 难度标签
2. **资料定位**：资料在哪？怎么用？→ 分级引导 + 使用说明
3. **学习路径**：怎么学才能过？→ 分阶段路线 + 任务清单
4. **避坑指南**：前人踩过哪些坑？→ 真实案例 + 正解
5. **实战经验**：学长学姐怎么说？→ 带年级/专业的反馈

### 写作原则
- **具体 > 抽象**："刷LeetCode链表10-15题" vs "多练习"
- **场景化 > 说教**："最后一周通宵爆肝，代码一团乱麻" vs "不要拖延"
- **可操作 > 建议**："提前4周启动，每周固定时间开发" vs "尽早开始"
- **真实 > 编造**：学长学姐反馈带年级+专业+具体分数

### 视觉设计
- **渐变卡片**：CSS Grid 响应式布局
- **配色方案**：
  - 数据结构：紫色系（理性、结构化）
  - 编译原理：橙红色系（硬核、挑战）
- **信息层级**：速览 → 详情 → 深度（符号 + 颜色 + 折叠）
